# bible_trivia_quiz_game

## description
A python Bible Trivia Quiz game that tests player's knowledge of the Bible though mutiple-choice questions.

## features
- Four quiz categories(Old testament, New testament, Bible characters, Books & verses)
- Randomized questions
- Input validation
- Automatic score calculation
- Persistent leaderboard usingMm a CSV file

## technologies used
- Python
- CSV file handling

## How to run
- Install python on your computer
- Download a clone of this repository
- Open the project folder in your terminal
- Run the command

## project files
- 'quiz.py' - contains the quiz program
- 'leaderboard.csv' - stores players' scores
- 'README.md' - provides project documentation.
